# 🚀 Community Contributors

A beginner-friendly open-source project where developers, students, and tech enthusiasts can showcase themselves by adding a simple JSON profile.

## 🌍 Purpose

This repository helps people:

* Make their first GitHub contribution
* Learn the Pull Request workflow
* Connect with developers worldwide
* Showcase their skills and projects

---

## 📂 Project Structure

```text
community-contributors/
│
├── README.md
├── CONTRIBUTING.md
├── schema.json
│
└── contributors/
    ├── vivek-kumar.json
    ├── john-doe.json
    └── ...
```

---

## 📄 Contributor Format

Create a JSON file inside the `contributors` folder.

Example:

```json
{
  "name": "Vivek Kumar",
  "country": "India",
  "role": "Student",
  "github": "https://github.com/vivekprajapati89",
  "linkedin": "https://www.linkedin.com/in/vivek-prajapati70040/",
  "highlight": "Built a calculator using Python."
}
```

---

## 🤝 How to Contribute

1. Fork this repository
2. Clone your fork
3. Create a new JSON file in the `contributors` folder
4. Follow the required format
5. Commit your changes
6. Open a Pull Request

---

## 📜 Rules

* One contributor profile per person
* Follow the JSON format
* Keep information professional
* Do not modify other contributor files
* Be respectful and welcoming
